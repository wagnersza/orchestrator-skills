One interface. The sha-prefix floor, the key set and the malformed-line rule move inside the implementation, where no caller can hold a second opinion.

Problem

Three modules each implement “is the record green at HEAD”, and they already disagree.

Solution

One module owns the rule; the three become call sites of one interface.

Wins

  • locality: one rule, one module
  • leverage: one interface, three call sites
  • divergence becomes unrepresentable
  • interface shrinks; implementation absorbs it
  • tests hit one interface, not three
  • delete two readers

Widen the stall predicate past the checklist mtime

Speculative
  • scripts/worker_state.py — the stalled outcome

The stall window reads the checklist file's timestamp. A worker that edits six source files for thirty minutes without ticking a box reads as stalled. Observed live on #204: a false stalled wake against a worker with six modified files.

This is a behaviour defect in one predicate, not shallowness in a module. It wants a bug report, not a deepening.

Top recommendation

Collapse the Gate record into one module

It is the only candidate with a reproduced contradiction: two hooks read one file and give a worker opposite answers. Story #198 exists to make a gate deterministic, and three readers of one record is the last place that promise is still soft.
